## Текущая реализация

- В `cutoff-game` находится отдельный проект Godot 4.7.2: нативный клиент Windows и выделенный Godot-сервер по ENet/UDP. Java и legacy не нужны для запуска.
- `maps/emergency-reactor-copy.map` скопирована побайтово из legacy. SHA256: `bba06fe78c0d82944db42b4449fb4097b7f9537f8eff29869b9a4af2e0d67d8f`. Не менять принятую продовую карту без отдельной задачи пользователя; редактор сохраняет только рабочие копии под другими именами.
- Сохранять минималистичный вид сверху. 3D пока не входит в согласованный перенос.
- Локальный запуск: `Играть.cmd`; второй клиент: `Ещё игрок.cmd`. Полная инструкция — `README.md`.
- Проверки: `tools/Test-Project.ps1`; сборки: `tools/Build.ps1 -WithLinuxRuntime`. После изменения игровых правил или сети выполнять соответствующие проверки настоящим Godot.
- Ничего не развёртывать и не перезапускать на VPS до локальной проверки пользователем и его дальнейшей задачи.
- Карты комнат выбирает сервер. Протокол 2 автоматически передаёт клиентам карту комнаты; нельзя возвращать требование вручную устанавливать одинаковые файлы всем игрокам. Пользовательские карты сохраняются отдельно в `server_maps`, продовая карта защищена.
- Редактор карт доступен через `Редактор карт.cmd`, после подключения и создателю комнаты до матча. Используется оригинальный браузерный редактор: `editor/editor.js` и `editor/styles.css` перенесены побайтово, HTML-секции сохранены. Не заменять его упрощённым инспектором JSON. Окно Godot обслуживает его через `scripts/editor_http.gd` только на localhost. Сохранение локальной копии и её загрузка на игровой сервер — разные операции, объединённая кнопка выполняет обе.
- После изменений триггеров/ИИ выполнять `tests/revision_test.gd`: реальные области и механизмы, все 27 маршрутов принятой карты, в том числе с 74 противниками одновременно. Сравнение с legacy и известные отличия — `COMPARISON.md`.

- Для изменений редактора выполнять `tests/editor_test.gd` и `python tests/editor_http_test.py`; после упаковки — `python tests/editor_http_test.py --pack`. Базовый редактор, стили и интерфейс находятся в `editor/`, интеграционные дополнения — отдельно.
