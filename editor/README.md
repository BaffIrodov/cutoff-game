# Перенос оригинального редактора

Редактор скопирован из `cutoff-game-legacy/src/main/resources/static`, который использовался только для чтения:

| Часть | Перенос |
| --- | --- |
| `editor.js` | Побайтовая копия всех 1854 строк оригинала: палитра, инспектор, механизмы, маршруты, рисование, изменения размера, история, черновики и сохранение |
| `styles.css` | Побайтовая копия исходных стилей |
| HTML | Обе секции `editor-menu-screen` и `editor-screen` перенесены без изменений. Убраны экраны старой браузерной игры и её `app.js`; добавлена самостоятельная оболочка редактора |
| `template.map` | Побайтовая копия исходного `maps/default.map`, используемая только командой «Создать из шаблона». Это не продовая карта; в каталог игры она автоматически не добавляется |
| API | Вместо Java-контроллера — локальная служба Godot, совместимая с исходными запросами `/api/editor/maps` |
| Дополнения | Отдельные `integration.js` и `integration.css`: открытие `.map`, загрузка сохранённой карты на игровой сервер, состояние подключения и защита продовой карты |

Контрольные суммы оригинальных JS/CSS — в `provenance.json`. Проверки подтверждают их неизменность.

## Сравнение с прежним Godot-редактором

| Возможность | Прежний | Перенесённый оригинал |
| --- | --- | --- |
| Свойства механизмов | Преимущественно JSON | Поля и списки исходного инспектора |
| Новые сложные механизмы | Дублирование существующего | Полная палитра, включая шлюзы на 2/3/4 игроков, мост, карман доверия, заслон, реле и отсечку |
| Карты | Файл-копия текущей карты | Список, открыть, копировать, шаблон, пустой туннель, импорт |
| Размеры объектов | Shift и перетаскивание | Оригинальные белые ручки и поля ширины/высоты |
| Выбор объектов | На холсте | Холст и сгруппированный список |
| Несохранённые правки | Только в памяти | Автоматический черновик браузера и восстановление |
| Конфликт вкладок | Не контролировался | ETag/If-Match, отказ от перезаписи чужих изменений |
| Загрузка в игру | Через Godot-панель | Из исходного интерфейса отдельной кнопкой, с подтверждением игрового сервера |

## Запуск и сохранение

`Редактор карт.cmd` открывает окно «Отсечка» и вкладку браузера. Из запущенной игры используй кнопку «Редактор карт». Оставь игру открытой: она обслуживает локальный редактор. Java и Python для использования не нужны.

«Сохранить карту» записывает рабочую копию в `maps/`. «Скачать .map» экспортирует текущие правки. «Сохранить и загрузить на игровой сервер» сначала подтверждает локальное сохранение, затем отправляет файл через действующее ENet-подключение и ждёт ответа сервера.

Открытие принятой продовой карты автоматически вызывает команду оригинала «Создать копию». Её исходный файл и `legacy` не перезаписываются. Импорт тоже создаёт отдельную копию при совпадении ID.

Локальная служба слушает только `127.0.0.1`, обычно порт 9081. Она не требует открытия дополнительного порта VPS. На сохранении проверяются данные карты и версия файла; запросы других сайтов и запросы без локальной сессии отклоняются.

## Проверки

- `tests/editor_test.gd`: каталог, исходные файлы, копии, сохранение, ETag, конфликты, ошибочные данные и защита продовой карты.
- `python tests/editor_http_test.py`: настоящая служба Godot и игровой сервер, HTTP-запросы, сохранение на диск, импорт и загрузка по ENet.
- `python tests/editor_http_test.py --pack`: тот же путь из собранного PCK, включая все HTML/JS/CSS.
- В браузере проверены открытие продовой карты через копию, редактирование HP/маршрута, сохранение и загрузка в игру, создание тройного шлюза и отмена, изменение размера стены белой ручкой и отмена.

Основной редактор не переписан на GDScript: используется его исходный браузерный интерфейс, а Godot обслуживает файлы и интеграцию с игрой.
